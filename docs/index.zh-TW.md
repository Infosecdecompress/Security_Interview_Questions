## 一起貢獻

!!! tip "一起讓內容更完整"
    - **新增題目或答案** — 到對應主題發一個 Pull Request。有想分享的面試問題或補充答案，歡迎直接建 Pull Request。
    - **發現錯誤** — 如果分類、題目或答案有誤，請開一個 Issue。
    - **建議更好的分類** — 歡迎到 Discussions 討論。

目前內容多以英文、美國資安職缺為主 — 非常歡迎協助翻譯成中文或其他語言。
