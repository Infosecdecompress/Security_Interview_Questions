# 面試與學習訣竅

這些面試與學習訣竅來自 [Grace Nolan](https://github.com/gracenolan) 的 [Interview Study Notes](https://github.com/gracenolan/Notes)，經同意整合於此。

**面試訣竅**

- 提出問題
  - 問題會激發你對答案的渴望。
  - 在學習時對自己提問，也對一起學習的夥伴提問。
  - 問題能揭示你如何思考問題。
  - 向你的面試官提出許多問題。他們常常刻意問一些細節很少的問題。

- 說出你正在想的
  - 面試官只能根據你所*說出來*的內容來評估你是否適合這份工作。
  - 如果你不把思考過程說出來，面試官就不知道你懂些什麼。
  - 練習把你對某個主題所知道的一切都說出來，即使是你覺得可能無關緊要的細節也一樣。
  - 為你的程式解法寫下虛擬碼，這樣你就不必把所有東西都記在腦子裡。

- 減輕認知負擔
  - 如果基礎架構很複雜，把你認為它長什麼樣子畫出來。
  - 為你寫的程式撰寫測試與預期輸出，並用它們來測試你的程式。
  - 對題目做筆記，以免忘記重要的細節。

- 準備
  - 事先準備好你想問面試官的問題，這樣當天就不必臨場才想。既然面試也是你了解這個職場的機會，我就問了關於這份工作最糟糕之處的問題。
  - 帶一些小點心，裝在不會發出聲音、不會造成干擾的盒子或容器裡。一整天適時補充一點糖分，有助於你的解題能力。
  - 保持水分充足，如果需要的話，每場面試之間去一趟洗手間。

- 進行模擬面試
  - 一直做到你感到自在、能夠輕鬆地把問題講清楚為止。
  - 請對方出一些你絕對不會的超難題目。
  - 練習置身於那種你對被問到的主題毫無頭緒的不自在處境中，並從第一原理（first principles）一步步推導出來。
  - 一定要做啊啊啊，沒錯，安排這些模擬面試可能很麻煩，但它*真的值得*。

**學習訣竅**

- [Coursera 上的 Learning How To Learn 課程](https://www.coursera.org/learn/learning-how-to-learn)非常棒也非常實用。可以修完整門課，或閱讀[這篇 Medium 上的摘要](https://medium.com/learn-love-code/learnings-from-learning-how-to-learn-19d149920dc4)。
- 追蹤各個概念——「待學習」、「複習中」、「已完成」
  - 任何我無法輕鬆解釋的名詞都寫到便利貼上。
  - 一張便利貼寫一個名詞。
  - 「待學習」、「複習中」、「已完成」寫在我的白板上，我在這些類別之間移動便利貼，每隔幾天就處理一次。
  - 我每天查閱名詞，並且每當想起這些即將到來的面試時（很頻繁），就練習回想這些名詞並向自己解釋一遍。
  - 我隨身帶著一本筆記本，寫下名詞與解釋。
- 讓學習更有針對性
  - *認真*想想你要應徵的是哪個特定團隊，他們想要什麼技能？如果你不確定，就去問一定會知道的人。
- 找出你的弱點。
  - 如果你在程式設計上比較弱，又發現自己在逃避它，那就把大部分的學習時間花在這上面。
- 閱讀
  - 閱讀相關書籍（你不必從頭讀到尾）。
  - 在網路上查資料時，避免點超過兩層以上的參照連結，這能讓你免於陷入瀏覽器分頁地獄。
- 心理健康
  - 先照顧好你的基本需求——睡眠、好好吃飯、喝水、適度運動。你最了解自己，所以做對你最好的事。
  - 你的價值不只是你的經濟產出，記得把自我價值與薪水分開看待。
  - 認清面試的本質——它們*並不是*衡量你「夠不夠好」的標準。
